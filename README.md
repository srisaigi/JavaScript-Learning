This repository contains my **JavaScript solutions** for the **LeetCode “30 Days of JavaScript” challenge**.

## 🚀 About the Challenge

The **30 Days of JavaScript** challenge on LeetCode focuses on:
- Understanding JavaScript fundamentals
- Learning how JavaScript behaves internally
- Writing clean and efficient code
- Improving problem-solving skills

Each problem builds confidence in using JavaScript for interviews and real-world development.
